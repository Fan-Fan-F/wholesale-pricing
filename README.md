# Wholesale Pricing · B2B 阶梯定价与报价单

面向批发/定制类电商的定价工具：**数量阶梯价 × 客户等级折扣**双重定价引擎，
试算后一键生成可打印报价单。

## 功能

- 4 种定制商品，各带 4-5 档数量阶梯价
- 4 级客户体系：零售 / 银牌 95 折 / 金牌 9 折（账期 30 天）/ 铂金 85 折（账期 60 天）
- 试算面板实时显示：命中档位、等级折扣节省额、**「再买 X 件享更低价」引导**
- 报价单：多行明细、行删除、客户名称、有效期计算、合计
- **打印优化**：`@media print` 隐藏操作区，直接打印/导出 PDF 即为正式报价单
- 定价引擎（`pricing.js`）纯逻辑，Node/浏览器通用

## 运行

浏览器直接打开 `index.html`。
